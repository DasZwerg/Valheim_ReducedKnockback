# Changelog

## 1.1.0
- Knockback is now enforced every time an attack starts, so mods that rewrite weapon stats after loading (such as Valheim Armory re-applying its config) can no longer restore the old knockback.
- Effects spawned by two-handed weapons (such as lightning AoEs) can no longer push harder than the weapon's own normalized knockback.
- Fist weapons are no longer affected.
- Two-handed pickaxes are now normalized like other two-handed melee weapons.
- The Iron Mace reference is picked up even if it isn't loaded yet on the main menu.

## 1.0.0
- Initial release.
